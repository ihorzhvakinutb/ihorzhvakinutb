## Engineering Style

I prefer systems that stay readable as they grow: small focused modules, clear naming, reusable components, and stable architecture before visual polish.

For embedded and HMI work, I prioritize reliability, low memory usage, non-blocking update logic, and interfaces that are easy to read in real operating conditions.

For game development, I focus on clean gameplay loops, satisfying feedback, performance on Android, and UI that feels premium without becoming visually noisy.
